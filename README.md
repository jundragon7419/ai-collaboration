# aicollab

여러 AI 모델에 기획자, 코더, 테스터, 리뷰어 역할을 배정하고, 정해진 순서로 기획, 구현, 검사, 리뷰를 돌리는 로컬 CLI 도구입니다. Claude Code와 Codex CLI 같은 공식 CLI를 호출하고, 결과는 로컬 브랜치에 커밋한 뒤 사람이 확인하면 push합니다.

현재 상태: 기획 단계. 아직 설치해서 쓸 수 있는 버전은 없습니다.

## 하려는 것

- 역할마다 회사와 모델을 고릅니다. 같은 모델에 다른 역할을, 다른 모델에 같은 역할을 줄 수 있고, 한 회사 모델만으로도 동작합니다.
- 협업 흐름은 "기획 → 코더 → 리뷰어" 또는 "기획 → 코더 → 테스터 → 리뷰어" 중에서 고릅니다.
- 코더가 끝나면 도구가 저장소의 검사 명령(테스트, 린트 등)을 직접 실행합니다.
- 리뷰 지적은 P0부터 P5까지 등급을 매기고, 고른 등급까지의 지적이 남아 있으면 통과하지 않습니다.
- 결과는 로컬 브랜치 `aicollab/<run_id>`에 커밋합니다. push와 Draft PR 생성은 사람이 확인한 뒤에만 하고, merge는 하지 않습니다.

## 쓰는 모습 (예정)

```shell
cd 내-저장소
aicollab setup            # 흐름, 역할별 모델, 검사, 차단 등급, 공개 방식 설정
aicollab doctor --probe   # CLI 설치, 로그인, 모델 접근 확인
aicollab run "빈 입력일 때 오류를 반환하도록 parser 수정"
```

필요한 것: Git, 쓰려는 AI의 공식 CLI(Claude Code, Codex CLI)와 각자의 로그인. PR까지 쓰려면 GitHub CLI(`gh`).
